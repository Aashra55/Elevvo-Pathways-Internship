# Collapsible Sidebar

## 📌 Description
A responsive collapsible sidebar component built with **HTML, CSS, and JavaScript**.  
The sidebar can smoothly open/close when toggled, includes a placeholder for a logo, and has navigation links with icons.  

---

## ✨ Features
- Logo placeholder at the top  
- 4–5 navigation links with icons  
- Toggle button to open/close sidebar  
- Smooth open/close animation  
- Responsive on mobile screens  

---

## 🛠️ Tools & Technologies
- HTML  
- CSS  
- JavaScript  
- FontAwesome Icons
---

## 🚀 How to Run
1. Clone or download the project.  
2. Open `index.html` in any browser.  
3. Click the toggle button to open/close the sidebar.
